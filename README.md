# Todo App

A simple and responsive Todo App built using React.js and Tailwind CSS.

## Features

* Add new todos
* Prevent duplicate todos
* Mark todos as completed
* Unmark completed todos
* Delete todos
* Numbered todo list
* Responsive design

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Vite

## React Concepts

* useState
* Props
* Event Handling
* Form Handling
* map()
* filter()
* Conditional Rendering

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

## Project Purpose

This project was created to practice React fundamentals and build a functional Todo application.
